    Что открывается по этажам

    «Очистить номер B» означает после первого прохождения этого этажа. Содержимое гачи зависит от вашего «достигнутого уровня» (самый глубокий этаж, на который вы можете войти в данный момент: самый глубокий очищенный этаж + 1).

    Когда количество слотов для загрузки увеличивается

    Количество различных ловушек, которые вы можете взять с собой на пробежку (слоты для снаряжения), увеличивается, когда вы очищаете этажи ниже. Награды за наборы в сложном режиме и награды за этапы в пещере также повышают его. Максимум — 12.

    ПолСлоты для загрузки
    Прозрачный B4До 4
    Прозрачный B40До 9
    Прозрачный B60До 10
    Прозрачный B80До 11
    Прозрачный B100До 12

    Стековое размещение (после очистки B10)

    • Вы можете поместить несколько одинаковых ловушек на одну плитку. Выберите число с помощью «- count +» в меню ловушки.
    • Один из них расходуется каждый раз, когда срабатывает ловушка.
    • Складывать можно только те ловушки, которых у вас есть две или более. Некоторые ловушки (например, деревянная доска с шипами) можно размещать только по одной.
    • Как только B10 очищен, он работает в сюжете, сложном режиме и в пещере.

    Виды гачи

    Гачей четыре: две для ловушек и две для снаряжения.

    ГачаРасходыГде
    Гача ловушек (обычная)Камни (100 для одного, 450 для 5)Мастерская Гордона
    Гача ловушек (платно)Покупка в магазине (цену проверяйте в игре)Мастерская Гордона
    Гача снаряжения (обычная)Камни (100 для одного, 450 для 5)Лавка снаряжения
    Гача снаряжения (платно)Покупка в магазине (цену проверяйте в игре)Лавка снаряжения
    • У платных гач есть потолок: каждый 50 тянет за Гачу-ловушку, а каждый 50 тянет за Гачу с бронёй (Глоссарий и часто задаваемые вопросы).
    • Шансы и составы указаны на странице гачи. Это реальные вероятности для самого дальнего доступного вам этажа.
    • Снаряжение состоит из четырёх частей: головной убор, одежда, обувь и аксессуар. Можно надеть по одному предмету каждой части. Каждая часть появляется начиная с определённого этажа (см. страницы снаряжения).

    Снаряжение и улучшения (после прохождения B4)

    • Ловушки и снаряжение становятся сильнее по мере повышения их уровня, а уровень повышается вместе с опытом.
    • Опыт, необходимый для следующего уровня, равен 5 x текущий уровень.
    • Максимальный уровень ловушки зависит от ее редкости. См. Таблицы обновлений.
