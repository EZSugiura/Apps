    COMBO計算器

    選擇陷阱、等級、同一回合觸發的陷阱數（COMBO），以及連續命中同一敵人的回合數（CHAIN）。假設對同一敵人使用同一種陷阱，顯示每次傷害與總傷害。

    計算方式

    與遊戲傷害程式（game_core）使用的公式相同。所有數值皆由遊戲資料產生。

    傷害 = 四捨五入（陷阱威力 x COMBO倍率 x CHAIN倍率）- 敵人護甲
（低於最低傷害時以最低傷害計算）
    • COMBO倍率：由陷阱在本回合中的順序決定（第1個、第2個……）。超過表格最後一列後倍率不變。
    • CHAIN倍率：由連續命中同一敵人的回合數決定。從表格最後一列起倍率不再增加。COMBO與CHAIN會相乘。
    • 取整：先計算威力 x COMBO x CHAIN，再四捨五入一次（0.5進位）。接著扣除護甲；若低於最低傷害（1），則以最低傷害計算。陷阱有多個傷害效果時，各效果分別計算後再相加。
    • 護甲：敵人的護甲特性會在較深樓層扣除更多傷害。請直接輸入每次命中時扣除的數值（0 = 無護甲）。
    • 未包含：屬性反應（油 + 火、潮濕 + 雷、凍結 + 物理等）、裝備技能（陷阱傷害提升、COMBO倍率提升等）、盾牌和頭盔敵人的減傷、Boss特殊處理。
